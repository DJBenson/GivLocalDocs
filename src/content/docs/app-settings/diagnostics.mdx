## Support Bundle

Creates a single zip file ready to share with support. It contains a register dump for each discovered inverter and the debug log, plus, when records exist, `write.log` (every setting written to each inverter) and `faults.log` (every fault the app has recorded for each inverter). Records are grouped by inverter serial number and are not limited by date, and a file is left out if there is nothing to record. This is the fastest way to get INVLocal-side and inverter-side diagnostic data to support in one step. Like the Debug Log, the bundle only leaves your device when you choose to share it.

## Connection Benchmark

Tests each available connection method against your inverter and recommends the best one for your hardware and network.

<Steps>
1. Open **Settings → Diagnostics → Connection Benchmark**
2. Tap **Run Benchmark**
3. INVLocal will test each method in turn
4. The recommended method is highlighted - tap **Apply** to use it
</Steps>

Previous benchmark results are shown so you can compare across sessions.

## Inverter Method

Selects the connection strategy INVLocal uses to communicate with your inverter. Method 3 is the default and works for most devices. If you experience connection issues, run the Connection Benchmark to find the best method for your setup.

## Verbose Frame Logging

When enabled, INVLocal captures the raw bytes sent and received in each communication with the inverter. This is primarily useful for bug reports or diagnosing unusual behaviour.

<Aside type="caution">
  Verbose Frame Logging generates large amounts of data quickly. Disable it once you have captured the information you need.
</Aside>

## Debug Log

INVLocal maintains an internal debug log that can be exported for troubleshooting. Use **Export** next to **Debug Log** to share it, or **Clear** next to **Clear Log** to reset it.

<Aside type="tip">
  Looking for **Confirm Writes** or **Confirm Commissioning Writes**? Those moved to [Settings → General](/app-settings/general/). Looking for **Reset App Defaults**? That moved to [Settings → App Data](/app-settings/app-data/).
</Aside>
