Open **Settings → App Data** to clear everything INVLocal has stored locally.

## Reset App Defaults

<Aside type="caution">
  This clears all settings, saved devices, and cached data. Use as a last resort when the app is in an unrecoverable state.
</Aside>

**Settings → App Data → Reset App Defaults** wipes all preferences and returns INVLocal to a clean state, as if freshly installed. Run a scan afterwards to rebuild the device cache.
