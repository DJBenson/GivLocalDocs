## Refresh intervals

| Setting | Description | Default |
|---------|-------------|---------|
| Live Data Refresh | How often the Dashboard updates (power flow, battery SOC, quick stats) | 10 seconds |
| Full Telemetry Refresh | How often the slower, more detailed register read runs | Longer interval |

Live data refresh can be set between **10 and 120 seconds** in steps of 10. A shorter interval gives more responsive readings but generates more network traffic to the inverter.

## Polling method

Controls how INVLocal reads data from the inverter:

| Method | Description |
|--------|-------------|
| Default | Splits live data and detail reads into separate passes. Recommended for most setups. |
| Full Telemetry | Reads all data in a single pass. Useful for diagnostics but slower. |
| Battery Meter | Polling optimised for battery meter-style monitoring. |

If you are unsure which method to use, run the **Connection Benchmark** tool in **Settings → Diagnostics** - it tests each method against your hardware and recommends the best fit.

<Aside type="tip">
  Looking for the max power options for Charge Now / Discharge Now? Those live in [Settings → Quick Actions](/app-settings/quick-actions/), not here.
</Aside>

## Adaptive Inverter Connection

When enabled, INVLocal learns safe connection timings for each inverter and connection route (local network, Tailscale, port forwarding) and adjusts its own request pacing accordingly. It never changes inverter controls or Modbus registers - it only affects how INVLocal talks to the device.

Tap **Adaptive Status** to open a details view showing the inverter and route being learned, the current status and confidence level, how many observations have been made, the dashboard refresh allowance, initial response allowance, request pacing, and when the timings were last adjusted. From here you can also reset the learned data back to defaults.
