The Dashboard is built from individual widgets that you can add, remove, and reorder to suit what you care about most.

## Entering edit mode

Long-press anywhere on the Dashboard to enter edit mode. A panel appears at the top showing **Available widgets** - a palette of everything not currently on your Dashboard - along with **Clear**, **Reset**, and **Done** actions.

<a href={availableWidgets.src} target="_blank" rel="noopener">
  <Image src={availableWidgets} alt="Editing Portrait Layout panel showing the Available widgets palette and Clear, Reset, Done actions" />
</a>

Tap the **+** on any widget chip to add it to your Dashboard.

<Aside type="note">
  Portrait and landscape use separate layouts. Customising one doesn't affect the other, and the panel title reflects whichever orientation you're currently editing.
</Aside>

## Available widgets

| Widget | Description |
|--------|-------------|
| Power Flow | The full animated power flow diagram |
| Power Flow Tile | A compact tile version of the power flow diagram |
| Quick Actions | Charge Now / Discharge Now / Pause buttons |
| Battery Swipe | Swipeable battery summary card |
| Battery Plant | Combined battery plant summary |
| Inverter Batteries | Per-inverter battery breakdown |
| Chargers | EV charger status tiles |
| GivTCP-style card | Battery card in the style used by GivTCP, showing capacity, charge/discharge totals, and timing estimates |
| Energy Stats | Daily generation, import, export, and consumption totals |
| Connection | Connection status summary |

If you have more than one battery, an individual widget is also offered for each one (e.g. **Battery 1**, **Battery 2**).

## Multi-inverter widgets

<Aside type="note">
  Multi-inverter widgets require **GivLocal 1.0.5 or later**.
</Aside>

Three additional widgets let you compare data across several saved inverters side by side, rather than only the one you're currently connected to. They're offered in their own **Multi-Inverter** group at the bottom of the widget picker, separate from the widgets listed above.

| Widget | Description |
|--------|-------------|
| Battery Plant | SOC and battery power per pinned inverter (Live page), plus today's and lifetime charge/discharge totals (Stats page) |
| Energy Stack | Solar, home, import, and export energy per pinned inverter, for Today and Total |
| Power Stack | Live solar, home, battery, and grid power per pinned inverter |

<Aside type="caution">
  The multi-inverter **Battery Plant** widget shares its name with the single-device **Battery Plant** widget listed above - they are different widgets. You can tell them apart by which group they're added from in the widget picker.
</Aside>

Each of these widgets shows up to three slots. An empty slot displays a **+** - tap it to open **Choose an inverter** and pick from your other saved devices. Tap a filled slot to open that inverter, or use the remove badge while editing to unpin it.

## Removing and reordering

While editing, each widget already on your Dashboard shows two controls:

- A red **−** in the top-left corner - removes that widget
- A blue drag handle in the top-right corner - press and drag to move the widget to a new position

## Clear, Reset, and Done

| Action | Effect |
|--------|--------|
| Clear | Removes every widget from the layout you're currently editing |
| Reset | Restores the default widget set for the layout you're currently editing |
| Done | Exits edit mode |

If you clear everything, the Dashboard shows an empty state with a shortcut back into edit mode:

<a href={emptyState.src} target="_blank" rel="noopener">
  <Image src={emptyState} alt="Empty Dashboard state showing a plus button and instructions to add widgets" />
</a>

<Aside type="tip">
  To restore every default widget across **both** portrait and landscape layouts in one go, use **Settings → Dashboard → Reset Dashboard Layout** instead of the in-editor Reset, which only affects the layout you're currently editing.
</Aside>
