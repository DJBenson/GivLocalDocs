The Fault Log in the Inverter screen shows active and historical faults reported by your inverter.

## Viewing faults

Open **Inverter → Fault Log** to see a list of faults detected during polling. Active faults are shown at the top. Each entry shows:

- **Fault name** - a readable description decoded from the inverter's fault codes
- **Detected** - the date and time INVLocal first noticed the fault
- **Cleared** - the date and time the fault was no longer present, or an **Active** badge if it is still set

<Aside type="note">
  Timestamps show when INVLocal detected the fault, not when it actually occurred. The inverter doesn't expose fault event times over Modbus, so if the app wasn't polling when the fault happened, the detected time is the first poll after it was already set.
</Aside>

If a fault clears and later happens again, a new entry is created so the history is preserved.

## Fault alert banners

When a fault is detected, INVLocal can display an alert banner on the Dashboard. Enable this in **Settings → General → Show Fault Codes**.

</a>

## Clearing alerts

Once you have reviewed a fault you can clear the alert from within the Fault Log. This dismisses the banner but does not resolve the underlying fault on the inverter.

<Aside type="caution">
  Clearing an alert in INVLocal does not reset or acknowledge the fault on the inverter itself. If a fault persists, contact your installer or [Predictive Support LTD](https://predsupport.com/).
</Aside>
