## What's shown

### LV batteries
- Battery serial number, below the sheet title
- Per-cell voltage (mV). Cells reading 0 V are shown rather than hidden, so faulty cells are easy to spot
- Temperature readings
- Calculated State of Health (when BMS capacity data is available)
- BMS current and remaining capacity on newer models

### HV batteries (BMU)
- One page per module, with the module serial number
- Per-module cell voltages
- BMU and BCU pack data shown separately
- Each module's temperature sensors, using the sensor count reported by the battery's BCU (typically 12 per module)

## State of Health

When your battery's BMS reports capacity data, INVLocal calculates and displays a State of Health percentage. This reflects how much usable capacity remains relative to the original design capacity. It is shown automatically; there is no setting to turn it on.
